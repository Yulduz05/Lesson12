💻 Dasturchi Ko'zi: Massiv (Array)
// 1. Tadbirlar bitta Massivda (Array) saqlanadi const tadbirlar = [ { id: 0, nom: "Koinot Futboli ⚽" }, { id: 1, nom: "Sehrli Sirk 🎪" }, { id: 2, nom: "Robotlar Konserti 🤖" } ]; // Indeks orqali murojaat qilamiz: let tanlangan = tadbirlar[0];

🧠 Dasturlash Mantiqi:

  • Massiv (Array) — bu bir xil turdagi ma'lumotlarni qator qilib saqlaydigan sehrli quti.
  • Dasturlashda hisoblash 1 dan emas, 0 dan boshlanadi! [0], [1], [2].
Joriy qiymat: tadbirlar[0] = "Koinot Futboli ⚽"
2-Bosqich: Filtr va O'zgaruvchilar (Variables)

Sehrli Portalga Torting! 🌀

Yoqqan tadbirni portalga tashlang. Kompyuter uni O'zgaruvchi (Variable) ichiga joylaydi!

⚽ Koinot Futboli
🎪 Sehrli Sirk
🤖 Robotlar Konserti
🌀 Suring yoki bosing!
💻 Dasturchi Ko'zi: Tanlov va Filtr
// 2. Tanlangan tadbir O'zgaruvchiga (Variable) saqlanadi let tanlanganTadbir = "football"; // Portal elementni massivdan topib oladi: const natija = tadbirlar.find(item => item.id === tanlanganTadbir); console.log("Portal qabul qildi:", natija);

🧠 Dasturlash Mantiqi:

  • O'zgaruvchi (let) — kompyuter xotirasidagi yorliq. U istalgan vaqtda yangi qiymatni qabul qila oladi.
  • .find() metodi — butun ro'yxat ichidan bizga kerakli bitta elementni qidirib beradi.
Xotirada saqlandi: tanlanganTadbir = "football"
3-Bosqich: Obyektlar (Objects & Properties)

Qaysi Sektorda O'tirasiz? 🏟️

Stadion va uning sektorlari kompyuterda Obyekt (Object) ko'rinishida tuziladi!

💻 Dasturchi Ko'zi: Obyekt (Object)
// 3. Stadion va sektorlar Obyekt sifatida tavsiflanadi: const stadion = { sektorA: { nom: "Sharq", narx: 3, sigim: 500 }, sektorB: { nom: "G'arb", narx: 3, sigim: 400 }, vip: { nom: "VIP Zona", narx: 3, sigim: 100 } }; // Tanlangan sektor xususiyatini o'qiymiz: let tanlov = stadion["sektorA"];

🧠 Dasturlash Mantiqi:

  • Obyekt (Object) — kalit va qiymat (nom: "Sharq", narx: 3) juftliklaridan iborat tuzilma.
  • Xuddi pasport kabi har bir sektorning o'ziga xos xususiyatlari bor.
Tanlangan obyekt: stadion.sektorA.nom = "Sharq"
4-Bosqich: Shart Operatori (IF - ELSE)

Bo'sh O'rindiqni Toping! 🪑

Kompyuter har bir bosilgan o'rindiqni IF (agar) va ELSE (aks holda) orqali tekshiradi!

💻 Dasturchi Ko'zi: IF - ELSE Sharti
// 4. O'rindiqning holatini tekshirish sharti: let orindiq = { id: 5, band: false }; if (orindiq.band === true) { xatoOvozi(); // 🐻 Joy band! Qizil chiroq! ogohlantirish("Ayiqcha o'tiribdi!"); } else { yutuqOvozi(); // 🎉 Bo'sh! Yashil chiroq! tanlanganJoy = orindiq.id; }

🧠 Dasturlash Mantiqi:

  • IF (Agar) — shart to'g'ri (True) bo'lsa birinchi qism ishlaydi.
  • ELSE (Aks holda) — shart noto'g'ri (False) bo'lsa ikkinchi qism ishlaydi.
Shart natijasi: ELSE bloki ishladi (Bo'sh) ✅

// 5. Tranzaksiya va Sanagich mexanizmi: let paidCoins = 0; const targetCoins = 3; function tangaTushdi() { paidCoins += 1; // Qiymatni 1 taga oshirish if (paidCoins >= targetCoins) { holat = "TO'LANDI ✅"; biletChopEtishgaRuxsat(); } }

Sanagich holati: paidCoins = 0 / 3
6-Bosqich: Noyob ID va Shifrlash (QR Code)

Sehrli QR Chiptangiz Tayyor! 🎫

VIP CHIPTA 🌟

💻 Dasturchi Ko'zi: Noyob ID & Shifr
// 6. Takrorlanmas Noyob ID va QR kod shifrlash: function biletYaratish(tadbir, joy) { const uniqueId = "TICKET-" + random(1000, 9999); const qrKod = encodeQR(uniqueId + tadbir); return { id: uniqueId, qr: qrKod, holat: "TASDIQLANDI" }; }

🧠 Dasturlash Mantiqi:

  • Noyob ID (Unique Identifier) — har bir chiptani soxtalashtirishdan himoya qiladi.
  • QR Kod (Quick Response) — barcha ma'lumotlarni qora-oq piksellar ichiga shifrlab beradi.
Shifrlangan ID: #TICKET-8842-UZ
